IIFE is a JS Function which executes immediately after its created . It needn't be called in different lines.
Reasons to use IIFE:
i) DATA PRIVACY:  Variable ko global scope se protect krne ke liye.
ii) Avoiding Global Scope Pollution 
iii) One TiMe Initalization
iv) Executing async/await at the top order.
